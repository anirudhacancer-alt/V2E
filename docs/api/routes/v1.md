# `/v1` shell routes

**Source:** `apps/api/src/routes/v1.ts` (mounted at `app.route("/v1", v1)` in `index.ts`).

## Routes on `v1` itself

| Method | Path | Auth | Purpose |
| ------ | ---- | ---- | ------- |
| `GET` | `/v1` | No | API name, version, demo/auth hints. |
| `GET` | `/v1/ping` | No | `{ pong, timestamp }`. |
| `GET` | `/v1/debug/db-summary` | No | Demo-only SQLite path + row counts. |

## Sub-routers (mount order)

Each row is **`v1.route("<mount>", router)`**. The current public surface is flat by first segment, with nested sub-actions only when they target one concrete resource.

| Mount | Source file | Purpose |
| ----- | ----------- | ------- |
| `/projects` | `projects.ts` | Project list and CRUD only (`/v1/projects`, `/v1/projects/:projectId`). |
| `/dashboard` | `dashboard.ts` | Flat project dashboard read model (`?projectId=`). |
| `/standup-prep` | `standup-prep.ts` | Flat standup-prep read model (`?projectId=`). |
| `/ai` | `ai-jobs.ts` | One-shot AI jobs such as standup summary and voice-note extraction. |
| `/reviews` | `reviews.ts` | Technical review queue read model (`?projectId=`). |
| `/updates` | `updates-router.ts`, `update-actions.ts`, `update-extraction.ts` | Three mounts on `/updates`: create/list entry, update-scoped commands, then nested extraction (`update-extraction.ts`). |
| `/tasks` | `tasks-flat.ts`, `task-reviews.ts` | Flat task CRUD plus nested review actions. |
| `/cycles` | `cycles.ts` | Work cycles. |
| `/commitments` | `commitments.ts` | Commitments. |
| `/dependencies` | `dependencies.ts` | Dependency edges and overrides. |
| `/improvements` | `improvements.ts` | Improvement actions. |
| `/metrics` | `metrics.ts` | Reliability and pilot metrics read models. |
| `/standups` | `standups.ts` | Standup sessions and nested attendance/open/close actions. |
| `/notifications` | `notifications.ts` | Notifications. |
| `/users`, `/departments`, `/roles`, `/locations`, `/sites`, `/members` | platform entity routers | Platform entity CRUD. |
| `/files` | `files.ts` | File upload and file serving metadata. |
| `/attachments` | `attachments.ts` | Unified task/update attachments. |
| `/audit` | `audit.ts` | Audit log. |
